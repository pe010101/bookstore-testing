# Исходное задание — Spring Bookstore, Chapter 3

## Статус

- Разделы 1–4 — основная обязательная работа.
- Раздел 5 **Bookstore: A Little bit Front-end** прямо помечен в условии как **Extra**.
- Исходное условие предлагает продолжать собственное приложение Bookstore из GitHub.

## Что требуется

### 1. Добавить JPA и базу данных

- Добавить в проект поддержку JPA и базу H2, изменив `pom.xml`.
- Сделать класс `Book` entity-классом.
- Убедиться, что у книги нет поля `year`, поскольку это зарезервированное слово; в условии в качестве замены предложено `publicationYear`.
- Добавить `CommandLineRunner`, который заносит в базу несколько примеров данных.
- Создать `BookRepository` на основе `CrudRepository`.
- Настроить вывод SQL-запросов в консоль.
- Включить H2 Console.

### 2. Сделать страницу списка книг

- Создать шаблон `booklist.html`.
- Показать в нём все книги из базы данных в HTML-таблице.
- Добавить в контроллер метод, обрабатывающий GET-запрос к адресу наподобие `/booklist`.

### 3. Добавить создание и удаление книг

- Реализовать функции Create и Delete.
- Для создания книги добавить Thymeleaf-шаблон `addbook.html`.
- Для удаления использовать аннотацию `@PathVariable`.

### 4. Добавить редактирование книг

- Реализовать функцию Edit.
- На странице списка разместить ссылку Edit после ссылки Delete.
- По ссылке открывать текущую книгу на странице редактирования.
- Передавать в контроллер идентификатор текущей книги и помещать текущий объект книги в Model.

### 5. Extra: добавить Bootstrap

- Скачать `bootstrap.min.css` с сайта Bootstrap и положить его в `resources/static/css`.
- Подключить локальный CSS-файл в `booklist.html`.
- Добавить таблице класс `table table-striped`.
- Добавить кнопке Add Book класс `btn btn-success`.
- Добавить кнопке Delete класс `btn btn-danger`.

## Ожидаемый результат

Приложение Bookstore хранит книги в H2 через JPA, заполняет базу несколькими примерами, показывает их в таблице и позволяет создавать, удалять и редактировать книги. При выполнении Extra список и кнопки оформлены локально подключённым Bootstrap.

## Что сдавать

- После каждого основного этапа в исходном условии указано отправить все изменения в GitHub.
- Итогом должны быть актуальные изменения в собственном GitHub-репозитории приложения Bookstore.

## Примечания к трактовке

- `publicationYear` приведено в условии как пример допустимой замены запрещённого имени `year`.
- Для GET-маршрута используется формулировка «endpoint like `/booklist`»; `/booklist` — приведённый в задании ориентир.
- Extra не является частью обязательных разделов 1–4.
- Условие не устанавливает отдельные требования к тестам, обработке неизвестного id, структуре DTO или конкретным HTTP-маршрутам сохранения.
- Названия приложенных лекционных материалов и архивов сами по себе не являются требованиями задания.
