# Исходное задание — MySQL Booklist

## Статус

- Работа прямо помечена в исходном условии как **Optional**.
- Она относится к дополнительному пункту Chapter 4 и не заменяет обязательную работу с категориями.

## Что требуется

- Ознакомиться с примером StudentListJDBC из Moodle.
- Установить локальную MySQL через XAMPP.
- Использовать параметры, указанные в учебном условии:
  - имя базы данных — `test`;
  - имя пользователя по умолчанию — `root`;
  - пароль по умолчанию — пустой.
- Создать приложение, аналогичное Booklist с предыдущей недели, но использующее MySQL.

## Ожидаемый результат

Работает вариант Booklist, который хранит данные в локальной MySQL вместо базы предыдущего этапа и подключается к учебной базе `test`.

## Что сдавать

- В исходном условии явно сказано вернуть эту Optional-работу через Moodle.
- Конкретный формат загрузки следует выбирать в соответствии с полем сдачи, доступным в Moodle.

## Примечания к трактовке

- Пустой пароль указан как значение по умолчанию для учебной локальной установки XAMPP, а не как общая рекомендация по безопасности.
- StudentListJDBC указан как пример для изучения, а не как самостоятельный результат сдачи.
- Исходный текст не предписывает делать отдельную копию проекта или использовать Spring profile; это относится к способу реализации, а не к условию.
- В условии не заданы конкретные зависимости, properties-файлы, переменные окружения, структура таблиц, тесты или набор скриншотов.
- Название приложенного PDF или ZIP-файла не следует считать дополнительным требованием задания.
