# Исходное задание — Spring Bookstore, Chapter 4

## Статус

- Основная работа Chapter 4 — обязательная.
- Это продолжение собственного приложения Bookstore из GitHub, а не отдельный новый проект.
- MySQL из второго пункта исходного листа является отдельной **Optional**-работой и вынесен в самостоятельное задание 09.

## Что требуется

- Ознакомиться с примером StudentList из Moodle, в частности со связью Student–Department.
- Создать новую entity `Category` с полями `id` и `name`.
- Добавить связь one-to-many между `Book` и `Category`:
  - добавить в `Book` поле категории;
  - добавить в `Category` список книг `List<Book>`;
  - добавить getters и setters для новых полей;
  - добавить аннотации, описывающие связь one-to-many.
- Создать CRUD repository для entity `Category`.
- Добавить список категорий в форму создания книги:
  - передать категории из контроллера в Model;
  - показать названия категорий в выпадающем списке.
- Добавить категорию на страницу списка книг и показывать название категории каждой книги.
- Через `CommandLineRunner` добавить в базу несколько категорий.

## Ожидаемый результат

Существующее приложение Bookstore поддерживает категории книг: категории сохраняются в базе, книга связана с одной категорией, в форме создания доступен dropdown с названиями категорий, а на странице списка у каждой книги показана её категория.

## Что сдавать

- Отправить все изменения Chapter 4 в GitHub.
- Сдаётся обновлённый собственный репозиторий Bookstore с реализованной связью книг и категорий.

## Примечания к трактовке

- StudentList из Moodle указан как пример для изучения, а не как отдельный результат, который нужно сдавать.
- В условии требуется именно двусторонняя модель: поле категории в `Book` и список книг в `Category`.
- Условие не требует отдельного CRUD-интерфейса для управления категориями.
- Конкретные имена JPA-аннотаций, владельца связи, cascade-настройки, способ передачи выбранной категории и набор тестов в исходном тексте не детализированы.
- Названия приложенных лекционных материалов и архивов сами по себе не являются требованиями задания.
